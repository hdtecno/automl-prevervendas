# automl-prevervendas
O objetivo deste projeto é desenvolver um modelo de regressão preditiva

Objetivo
O objetivo deste projeto é desenvolver um modelo de regressão preditiva que permita: 

✅ Treinar um modelo de Machine Learning para prever as vendas de sorvete com base na temperatura do dia.
✅ Registrar e gerenciar o modelo usando o MLflow.
✅ Implementar o modelo para previsões em tempo real em um ambiente de cloud computing.
✅ Criar um pipeline estruturado para treinar e testar o modelo, garantindo reprodutibilidade.

Após treinar um modelo de ML para precer vendas com base na temperatura do dia fois possivel observar a capacidade de predição do modelo e margens de erro.
O registro do modelo foi realizado usando o MLFlow porem o deploy apresentou erro que será melhora avaliado para então criar o pipeline estruturado.
